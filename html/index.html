cactup

The easiest way to install and manage
Einstein Toolkit (Cactus) releases.

To install, run the following in your terminal:

curl --proto '=https' --tlsv1.2 -sSf https://cct.lsu.edu/~mmorris/cactup/cactup-init.sh | sh

cactup runs on Linux and macOS. It downloads the cactup manager, installs it to ~/.cactup/bin, and adds it to your PATH.

Don't have curl?
wget -qO- https://cct.lsu.edu/~mmorris/cactup/cactup-init.sh | sh

Once installed, get going with:

  • cactup list — see the available Einstein Toolkit releases
  • cactup install — install the latest release (or a chosen one)

cactup is developed at the LSU Center for Computation & Technology.
